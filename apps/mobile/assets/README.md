# App assets

- `fonts/` — bundled fonts. `Mukta` (OFL, Ek Type) covers Marathi/Devanagari and
  Latin; see `pubspec.yaml` → `flutter.fonts`. Add additional weights as needed
  (must be referenced in `pubspec.yaml` to be packaged).
- `images/` — brand and feature imagery. Add files here and list them (or the
  directory) under `flutter.assets` in `pubspec.yaml`. Placeholder directory for
  now.
